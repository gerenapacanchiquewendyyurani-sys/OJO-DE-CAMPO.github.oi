OJO DE CAMPO — CÓDIGO ORDENADO

1. Descomprime el ZIP.
2. Abre index.html en el navegador.
3. La página utiliza Tailwind CSS por CDN y una fotografía de Unsplash, por eso requiere Internet.
4. El panel se ajusta a diferentes tamaños de pantalla. Se reorganizaron los bloques para evitar que textos y tarjetas se monten entre sí.
5. Las cifras y el terreno son de demostración, no datos reales.
6. Para publicar en GitHub Pages, sube index.html y la carpeta assets.
